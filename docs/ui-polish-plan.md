# UI polish plan (WIP — доделать позже)

Статус: **в разработке**. Сейчас оболочка рабочая по функциям, но визуально всё ещё «homebrew sharp» на 480×272 soft-FB. Красивые CTF/ONEMenu темы выглядят иначе — этот план фиксирует *почему* и *что делать*.

## Почему темы красивые, а мы нет

| Красивая CTF / ONEMenu | OwnShell сейчас |
|------------------------|-----------------|
| Готовые PNG/TGA/GIM с AA, запечённым в арте | Векторы/SDF/текст рисуются в CPU 1:1 |
| GU + bilinear на текстурах | Soft framebuffer без фильтрации |
| Обои 480×272 (фото/градиенты) | Плоский fill |
| XMB/VSH или ya2d+PNG тема | Свой UI без asset-пака |

FreeType сам по себе не делает «как CTF». Зубцы на скруглениях при 1:1 + апскейл PPSSPP — ожидаемы.

## Что уже сделано (можно опереться)

- FreeType + встроенный Noto Sans subset (кириллица)
- Solid AA roundrect SDF (без hollow pill)
- Композиция ближе к концепту (табы, обложки, pill, HOME preview, settings)
- Host tests + `tools/smoke/ppsspp_ui.py`
- Провал GU/ya2d-попытки → откат на soft-FB (чёрный экран из‑за cull/init)

## План доработки (порядок)

1. **2× supersample soft-FB**  
   Рисовать в 960×544, box-filter → 480×272. Шрифт ~28px FT, радиусы ×2. Самый большой выигрыш без дизайнера.

2. **PNG chrome atlas**  
   Pill, рамки обложек, панели, иконки X/O/L/R — как ONEMenu (`buttons*.png`, `back.png`). Мягкие края в арте.

3. **GU textured blit** (после стабильного SS)  
   Atlas → `GU_LINEAR` + MODULATE. Без повторного «чёрного экрана»: без cull на 2D, правильный vabsptr, smoke-тест до merge.

4. **intraFont / PGF для латиницы (опционально)**  
   Кириллица остаётся на FT или кастомном TTF→текстура.

5. **Визуальный паритет с концептом**  
   Скриншот-дифф library / HOME / settings; smoke_ui пороги по cyan + не-чёрному кадру.

## Не делать в этом этапе

- Tauri / React как продукт PSP
- Glass blur / fake glow ради «красоты»
- Claim «готово / как CTF» без скринов smoke

## Критерий «готово по виду»

На PPSSPP (и желательно на железе): скругления без явной лесенки при обычном просмотре окна, текст читаемый как у нормального лаунчера, pill/карточки сплошные, `smoke_ui.py` зелёный.
